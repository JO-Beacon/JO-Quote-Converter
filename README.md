# JO-引号转换

JO-引号转换是一个使用 Flutter 开发的本地文本工具，用于将英文直引号转换为中文弯引号。目前面向 Windows 和 Android，不需要网络连接，文本处理与草稿保存均在设备本地完成。

作者：GitHub [JO-Beacon](https://github.com/JO-Beacon)

## 功能

- 将英文双引号 `"..."` 转换为中文双引号 `“...”`
- 将英文单引号 `'...'` 转换为中文单引号 `‘...’`
- 可开启启发式判断，尝试识别单双引号、英文撇号、长度单位和年代缩写；该判断不能保证覆盖所有歧义文本
- 可关闭启发式判断，让单双引号分别严格按照左、右、左、右的顺序机械配对
- 避免重复处理已有的中文引号
- 可选择排除 Markdown 围栏代码块与行内代码
- 支持复制转换结果和清空文本
- 支持跟随系统、浅色和深色三种外观模式
- 支持红、黄、绿、蓝、紫、灰六套配色，默认使用灰色
- 内置思源黑体简体中文版，包含 Regular、Medium 和 Bold 字重
- 实时保存原文、转换结果、Markdown 排除选项和启发式判断选项，关闭后再次打开仍可恢复
- 每次转换都会保存原文、转换结果和时间，并在历史记录面板中按最新优先展示
- 可将历史记录的原文和转换结果恢复到工作区，覆盖非空工作区前会二次确认
- 可单独删除历史记录，删除前会二次确认
- 桌面端使用左右分栏，窄屏设备自动切换为上下布局

## 使用

1. 在“原文”区域输入或粘贴文本。
2. 打开右上角“设置”，根据需要分别设置“排除 Markdown 代码”和“启发式判断”。两个选项互不影响。
3. 点击“转换”，在右侧或下方查看结果。
4. 点击复制按钮复制转换结果。

草稿会在文本变化后自动保存。正常关闭窗口、切换到后台或退出应用时，程序也会立即补写一次当前内容。

## 数据与隐私

本程序不需要账号，不会上传文本，也不包含后端服务。转换历史使用 SQLite 逐条保存在当前设备的应用数据目录中；当前草稿和相关选项通过 Flutter 的 `shared_preferences` 保存在当前设备上。

Windows 版会在首次启动新版数据目录时，将旧版 `com.localtools` 目录中的草稿、设置和历史记录一次性迁移到 `JO-Beacon` 目录。迁移不会删除旧数据。

## 开发

项目使用 Flutter 3.44.1 和 Dart 3.12.1 开发。

```powershell
flutter pub get
flutter run -d windows
```

运行检查：

```powershell
dart analyze
flutter test
```

部分 Windows 原生构建工具对包含非 ASCII 字符的项目路径支持有限。如果构建失败，建议将项目放在纯英文路径中再执行构建。

## 项目结构

```text
lib/
  main.dart             应用界面、主题与草稿恢复
  quote_converter.dart  引号转换与 Markdown 代码排除
  draft_store.dart      本地草稿存储
  history_store.dart    SQLite 历史存储与旧数据迁移
assets/
  fonts/                思源黑体字体文件
  licenses/             第三方字体许可证
test/                   转换逻辑与界面测试
```
